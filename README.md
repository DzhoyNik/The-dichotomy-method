## **WPF-приложение для решения уравнений методом дихотомии с визуализацией**

### **Общее описание проекта**

**Проект представляет** собой современное Windows-приложение, разработанное с использованием технологии WPF (Windows Presentation Foundation). Основная цель проекта — реализация численного метода дихотомии (метода половинного деления) для поиска корней нелинейных уравнений с последующей визуализацией результатов.

### **Ключевые особенности**

* **Удобный интерфейс** с интуитивно понятной организацией элементов управления
* **Мощная функциональность** для работы с математическими выражениями
* **Динамическая визуализация** процесса поиска корня на графике
* **Детальная статистика** вычислений с отображением всех промежуточных значений
* **Гибкие настройки** параметров поиска корня

### **Основные компоненты приложения**

* **Панель ввода** математических выражений с поддержкой синтаксического анализа
* **Графический модуль** для отображения функции и процесса поиска корня
* **Вычислительный блок** с реализацией метода дихотомии
* **Панель управления** параметрами вычислений
* **Модуль визуализации** результатов и статистики

### **Принцип работы**

Приложение позволяет пользователю:
* Вводить математические функции в специальном формате
* Задавать интервал поиска корня
* Настраивать точность вычислений
* Наблюдать за процессом поиска корня в режиме реального времени
* Получать детальный отчет о результатах вычислений

### **Технические характеристики**

* **Платформа разработки**: WPF (.NET Framework)
* **Графический интерфейс**: XAML
* **Вычислительные алгоритмы**: C#
* **Визуализация**: WPF Graphics
* **Совместимость**: Windows-системы

Приложение сочетает в себе простоту использования и мощные вычислительные возможности, что делает его отличным инструментом как для образовательных целей, так и для практического применения в математических расчетах.
